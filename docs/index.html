Search decides what the model gets to learn.

If feedback is expensive, the retriever cannot learn from every document. The search engine first decides what is even eligible to be scored. Our IRE project asks whether that search decision changes the usefulness of a limited supervision budget.

01 / The question

Where do you spend 20 expensive feedback calls?

Imagine a question asked of a search engine. It can retrieve hundreds of passages in milliseconds, but a stronger relevance judge is too costly to run over everything.

Key asymmetry

The selector can only choose among passages the ANN stage exposes. A missed passage gets no teacher label, hence contributes no teacher-feedback training signal in this pipeline.

The exact question in the research plan:

“Holding the retriever, reward model, feedback budget, post-training loss, and evaluation fixed, does changing the ANN/search procedure used to generate candidates change the final post-trained retriever?”

Direction 1 · Search / exposure

Change the candidate generator.

Use exact search, HNSW or IVF-Flat to create candidate lists. Keep scoring, selection, model and evaluation the same. Ask which useful examples become visible.

Direction 2 · Budgeted selection

Spend the same budget better.

Hold candidates fixed, then compare a simple high-rank selector with diversity-aware selection before expensive feedback scoring. This is closer to the Microsoft Data Selection objective.

Microsoft's research call also lists loss formulation and efficient post-training iterations. Your documented initial focus is Data Selection; the original plan is marked “Draft.”

02 / The learning loop

Five distinct mechanisms. Only one should change at a time.

Click a stage to see what it does. This distinction prevents a common error: ANN retrieval is not the same thing as sampling, teacher labeling, or training.

01 · Candidate generation

The query encoder maps a text query to a vector. The document encoder maps each document to a vector. A search index returns an ordered list of the best-matching vectors. Exact checks all items; HNSW navigates a graph; IVF searches selected vector clusters.

Variable to test in Direction 1: search algorithm and configured operating point. All downstream stages stay fixed.

Clear terminology: ANN Recall@200 measures agreement with exact nearest neighbors, not human relevance. MRR@10 evaluates whether relevant passages appear high in the final ranking. Those are different targets.

05 / Adversarial review

What a skeptical reviewer will attack.

These are reasons not to over-interpret the results, along with the exact controls that can distinguish a useful mechanism from an artifact.

01

High candidate recall, low selected overlap: selector artifact?

Reorder identical candidates; fix selected IDs; compare top-20, random-from-200, and rank-stratified policies. The previous selector sampled a deterministic query-specific permutation of rank positions.

02

No meaningful learning improvement established in the 50k pilot.

All trained branches had lower MRR@10 than the untouched ANCE checkpoint. Create a working teacher-supervised training baseline before attributing gains to backends or selection.

03

Unusual evaluation construction inflated apparent baseline ease.

The MS MARCO subset was assembled to contain known positives from train, calibration and evaluation. Use the official large corpus, pre-register query splits, audit near-duplicate texts and avoid label-informed corpus construction.

04

“Unlabelled” does not mean “irrelevant.”

Forcing every retrieved unlabelled passage to be a negative can create false negatives. Let a pinned cross-encoder score them, inspect known-positive disagreement, and use a loss that preserves soft relevance.

05

Data differences are not yet a novelty claim.

ANCE, RocketQA and SimANS already show that candidate/negative choice matters. A stronger contribution would identify when ANN recall fails to predict teacher-feedback utility, characterize why, and show an efficient fix.

06

Underpowered experiment and metric mismatch.

The ANCE run used one training seed. The SciFact run used two seeds. Compare at matched recall and separately matched cost, with multiple seeds, paired-query uncertainty, teacher-budget curves, and ideally a second domain.

07

SciFact contains cross-split duplicate query texts.

The SciFact manifest records two duplicate query-text groups spanning train/test IDs. IDs are disjoint, but text overlap remains a contamination concern. Repair the split before interpreting generalization.

08

“Teacher used” is not the same as “teacher feedback optimized.”

The separate SciFact run had a teacher and full student updates, yet most trained configurations still failed to beat its untouched checkpoint consistently. First diagnose training quality and teacher–dataset mismatch.

What not to say tomorrow

“We proved IVF improves retriever training,” “ANN choice causes a 56% loss of supervision,” “diversity improves performance,” and “this is already an A* result.” None follows from the completed evidence.

  • Ensure at least one simple arm improves development retrieval consistently.
Stage 1 · Main initial test

Freeze search; vary selection.

Proposed / not completed
  • Exact ANCE top-200 frozen candidate lists.
  • One known positive anchor + 19 selected = 20 teacher calls per query.
  • Compare top-ranked selection vs maximal marginal relevance (MMR) diversity.
  • Suggested 1,000 train queries × 20 calls = 20,000 scored pairs per arm; 3 paired seeds.
Stage 2 · ANN hypothesis

Vary only candidate generation.

Proposed / not completed
  • Exact vs HNSW vs IVF, with selector and feedback budget fixed.
  • Separate matched-recall and matched-latency comparisons.
  • Re-encode corpus with each updated model for final exact-search evaluation.
  • Report feedback budget vs final MRR/nDCG + latency, memory and uncertainty.

Primary success metric

Held-out MRR@10 after teacher-supervised training, evaluated by exact search on the same evaluation corpus. Plot the gain over the untouched model against the number of teacher-scored query–passage pairs.

Mechanism metrics

Selected-pool overlap, teacher-score distribution/spread, quality of hard negatives, redundancy, false-negative rate and (if affordable) gradient-direction disagreement. Each quantity answers a separate question.

Sharper long-term hypothesis

Standard ANN Recall@K may be a poor proxy for the learning value of candidates exposed under a feedback budget. This becomes publishable only if it survives selector controls, predicts downstream quality, and yields a validated improvement over strong baselines.

07 / A possible extension, not the submitted claim

What changes when the retrieval system belongs to an AI agent?

The same limited-exposure problem could apply when an agent retrieves past memories, tools, demonstrations or evidence. But the success metric must move from passage-ranking scores to downstream task success.

Information retrieval setting

Choose which passage to judge.

Search: retrieve documents for a query.
Budget: expensive relevance labels.
Objective: improve a dense retriever's held-out ranking.
Potential distortion: useful passages never exposed to the scorer.

Agent-memory setting · Hypothesis

Choose which memory to expose.

Search: retrieve prior actions, facts and plans.
Budget: context tokens, tool calls or adjudication effort.
Objective: downstream task success, supported evidence and latency.
Potential distortion: decisive memory is omitted from the agent context.

Keep the research threads separate.

ADAPTEX-MEM asks which memory structures, routes, indexes and fusion policies should exist or be used; the future-robust retention direction asks what should be stored before a future task is known. They are possible connections, not validations of the IRE post-training hypothesis. An agent extension needs its own strong baselines and causal design.
