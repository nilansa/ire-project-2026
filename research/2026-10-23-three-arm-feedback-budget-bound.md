# Three-arm selection-union budget bound — 23 October 2026

**Scope:** 50k MS MARCO/ANCE **300-update, no-teacher** pilot only. This is a CPU-only arithmetic analysis of recorded aggregates, not a new retrieval or teacher experiment. The separate SciFact pilot is excluded.

The original [no-teacher record](../survey/experiments/02-ann-backend-negative-selection-sanity.md) documents 1,000 training queries, 20 selected negative IDs per query per arm, and selected shared fractions of **0.44885** (exact/HNSW), **0.48055** (exact/IVF), and **0.4344** (HNSW/IVF). Treating each selected item as a `(query ID, passage ID)` key yields three sets `E,H,I`, each of size 20,000, with pair intersections **8,977**, **9,611**, and **8,688** respectively. The triple intersection `t=|E∩H∩I|` was *not* recorded.

By inclusion–exclusion, `|E∪H∪I|=60,000−8,977−9,611−8,688+t=32,724+t`. The aggregate pair intersections allow `0≤t≤8,688` (both endpoint counts have nonnegative Venn-region counts). Thus **32,724–41,412** distinct selected query–passage keys could occur across all three arms. Relative to the **31,312** distinct keys in HNSW∪IVF, including the exact-selected arm would require **at least 1,412 and at most 10,100 additional distinct keys** if these three historical selection sets and scores were all available. Under the *extra, unverified* assumption of exactly one separately scored **shared known positive per query**, the total across three arms would become **33,724–42,412** distinct keys; this is not a teacher-inference call count.

**Decision changed:** If original per-query selected IDs and teacher-score cache become available, first count the actual three-way intersection, then price the exact-retrieval positive control using *new distinct unscored* keys rather than allocating 20,000 new teacher calls by default. The broad aggregate interval is not a budget commitment. Teacher-cache availability and consumed optimizer rows must also be verified.

**Critical limitation:** This analysis uses only the no-teacher pilot's *three* pairwise overlaps. The 100-update teacher pilot reports the same HNSW/IVF aggregate overlap, but identical aggregates **do not establish identical per-query IDs or scoring slates across the two pilots**. No historical exact-arm teacher labels or cross-pilot ID parity have been recovered. The Venn endpoints certify aggregate cardinality feasibility, not query-by-query feasibility or reuse of historical logits. Do not infer matched teacher budgets, ANN causality, or any post-training improvement.

Reproduce from the repository root: `python3 -B experiments/selector-rank-falsification/three_arm_overlap_budget_bound.py`. This script checks the source literals, integer counts, endpoint region feasibility and union arithmetic; it does not run ANN, teacher inference or training.
